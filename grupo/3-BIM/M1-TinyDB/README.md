## 📋 Lista de Tarefas

Aplicativo desenvolvido no **MIT App Inventor** como atividade prática da disciplina de Desenvolvimento Mobile.

O projeto permite cadastrar, visualizar e excluir tarefas, utilizando o **TinyDB** para armazenar os dados localmente, garantindo que as informações permaneçam salvas mesmo após o aplicativo ser fechado.

### Funcionalidades
- Adicionar tarefas
- Visualizar lista de tarefas
- Excluir tarefas
- Limpar todas as tarefas
- Armazenamento local com TinyDB
